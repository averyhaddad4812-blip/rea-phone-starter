# Starter questions

**Just want an overview?** Use the Run button on GitHub instead (see the README). It's free and needs no Claude.

Copy any of these into Claude Code. Ask one or several at once, and swap in a different app whenever you like.

## Your first look

- "Set up REA and get Fossify Calculator from F-Droid."
- "Is this app file genuine? Who made it?"
- "Give me a quick tour of this app: what it is, what it asks permission for, and how big it is."

## Permissions and privacy

- "What permissions does this app ask for, and what does each one mean?"
- "Does this app use the Internet at all?"
- "Does this app have any parts that other apps can open?"

## Inside the app

- "What screens does this app have?"
- "What languages is this app translated into?"
- "Show me the app's text in Spanish."
- "How does this app start up when I open it? Explain it simply."

## Going deeper

- "Find the code that does [a feature] and explain how it works."
- "Why do so many names look scrambled?"
- "Compare what REA found with the app's real source code on GitHub."
- "Save what we found as a report I can read later."

## Good apps to practice on (all open source, all on F-Droid)

| App | Package id | Why it's fun |
|---|---|---|
| Fossify Calculator | `org.fossify.math` | Small and simple. A great first try |
| Fossify Notes | `org.fossify.notes` | See how a notes app stores your notes |
| Breezy Weather | `org.breezyweather` | Bigger. Pulls weather from many sources |
| AntennaPod | `de.danoeh.antennapod` | A full podcast player |
